# Irrigation System Plan — Worthington Springs Property

## System Basics
- Water source: private well, ~21 GPM at the 1" line, 50 psi static
- Design flow: 20 GPM per zone (1 GPM safety margin), one zone running at a time
- Controller: Hunter X2, 6 stations (existing — controller box survived, all wiring/pipe/valves/heads need replacing)
- Wellhouse location: between house and hangar (marked "WH" on site photo)
- Routing constraint: mainline runs north from wellhouse to the apron/runway edge, then east-west along the apron before branching south into each zone

**Total heads: ~19-21**
**Total irrigated turf: ~1.5 acres** (Zone 6's exact head count and placement depends on which patches are grass vs. mulch — field-verify before finalizing)

## Material List

**Heads & accessories**
- 15× large-radius gear-driven rotor (Hunter I-25 or Rain Bird 5000/Falcon series), 5-7 GPM nozzle, ~50ft radius — Zones 1-5
- 4-6× shorter-throw rotor or spray body, 25-35ft radius — Zone 6
- ~20-21× swing joints (one per head)

**Valves & control**
- 6× 1" electric solenoid valves (24V, one per zone)
- 1× jumbo valve box (or split into 2 if zone branch points end up spread out along the trunk rather than clustered)
- 1× 500ft spool 7-conductor direct burial irrigation wire (controller → wellhouse → trunk run to all 6 valves)

**Pipe**
- 1.25" Class 200 PVC mainline: ~425-475 ft (wellhouse → apron → trunk run); round up to a 500ft length
- 1" Class 200 PVC lateral pipe: ~800-1,000 ft (Zones 1-5 head-to-head runs; Zone 6 TBD after field walk)
- Fittings: tees, 90°/45° elbows, couplings, male/female schedule 40 adapters at each valve — buy after pipe runs are physically marked out, exact counts are hard to predict in advance
- PVC primer + cement

**Other**
- 1× backflow preventer (not required where you are, but cheap insurance)
- Optional: Hunter Wi-Fi module for the X2 controller, for remote access while traveling for work
